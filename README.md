# Agenda SP · Experimento de Curadoria Urbana · v0.1

Experimento funcional de curadoria urbana documentado em 03/09/2026.

## Status

Este repositório preserva a versão operacional da Agenda SP. A Agenda SP surgiu como ferramenta pessoal de curadoria de acontecimentos urbanos e demonstrou uma hipótese de relação futura com discovery, contexto e recomendação da urbanmate. **Essa relação é apenas uma hipótese e não constitui decisão de produto, roadmap ou arquitetura.**

## Produção

- URL pública: https://urbanmate.github.io/agenda-sp/
- Arquivo operacional: `index.html`
- Branch operacional: `main`
- Publicação: GitHub Pages

A URL pública deve ser preservada entre edições sempre que possível.

## Protocolo

Fluxo de atualização:

`comando → pesquisa → validação → base canônica → curadoria → atualização do HTML → publicação → link público`

Princípios:

- Rolezero pode ser usado como fonte relevante de descoberta, mas não como fonte única de verdade.
- Validar data, horário, local, preço, disponibilidade e ingresso em fontes oficiais sempre que possível.
- Marcar informação não comprovada como `a confirmar`.
- Classificar prioridade, ambiente e compatibilidade com chuva.
- Preservar a experiência mobile-first, filtros, favoritos via localStorage, detalhes, cópia de resumo e links operacionais.
- Não converter automaticamente o experimento em funcionalidade canônica da urbanmate.

## Governança

A documentação estratégica e os aprendizados completos estão registrados no Notion da urbanmate, em `02 · Produto & Operação`, na página **Agenda SP · Experimento de Curadoria Urbana · v0.1**.

O Google Drive mantém o arquivo documental do experimento. O HTML vigente permanece neste repositório para evitar cópias divergentes.
